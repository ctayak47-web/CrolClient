# CrolClient

Visual client mod for Minecraft 1.21.4 (Fabric).

## Features
- **Fullbright** — maximum brightness without night vision
- **Auto Sprint** — automatic sprint when moving
- **Auto Eat** — automatic eating when hunger is low
- **Glassmorphism GUI** — modern translucent UI with rounded corners

## Controls
- **Right Shift** — open mod menu

## Build
```bash
./gradlew build
```

## GitHub Actions
The project includes a CI workflow that automatically builds the mod on every push/PR.
